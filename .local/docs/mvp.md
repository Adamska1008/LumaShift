# LumaShift 初版需求

面向 Windows 游戏玩家的画面调节工具。最初需求来自《逃离塔科夫》：改善画面偏暗、偏灰的问题，同时提供比现有工具更直观的操作体验。

2026-09-26：已开始实现 Windows SDR 初版，采用 Tauri 2 + Rust + React / TypeScript。用户目前不开启 HDR；明确不需要开机自启。开发命令与验证记录见 [development.md](development.md)。

## 初版范围

- **Gamma 调节**：通过显示输出的 RGB 三条一维曲线调整画面。常用项为 Gamma、暗部提升、画面对比度；高级项为高光、曝光、色温倾向、黑位提升。Gamma 1.00 表示保留已有曲线，不是指定显示器的绝对 Gamma 为 1.0。
- **DDC/CI 调节**：控制显示器硬件参数，提供设备实际支持的亮度、对比度及饱和度。探测其他色彩控制能力，色温、RGB 增益、色调、锐度等列为可扩展候选，是否提供以具体设备能力及后续范围确认为准。
- **预设**：保存、选择和更新调节方案，包含 Gamma 设置及选用的 DDC/CI 参数。
- **全局快捷键**：支持给每个预设配置快捷键以直接切换，也支持配置开关效果、循环切换预设的快捷键。初始示例为桌面 F6、塔科夫 F7、开关效果 F9、循环预设 F10；支持自定义组合键及清除绑定。
- **系统托盘**：关闭主窗口后常驻 Windows 通知区域，继续保持效果并响应快捷键。
- **实时预览**：拖动控制项时直接应用到目标显示器，无需另点“应用”。
- **目标显示器选择**：允许用户明确选择要调整的显示器；初版围绕单个选定目标操作。

## 交互约定

### 调整与保存

- 画面直接呈现当前调整结果，以实际屏幕效果作为预览。
- 连续拖动时在后台合并待写入的调整，优先处理最新值，避免阻塞界面或积压旧设置。
- 调整不会自动覆盖已保存预设；用户明确保存后才更新预设。
- 切换预设时保留本次运行的未保存草稿；重新启动只加载明确保存过的配置。
- 提供调整前状态与当前设置之间的快捷对比。
- 主调节页在最小支持窗口 880×680 内完整显示常用参数和底部操作；高级参数超出时在各自面板内部滚动，不让整个调节页滚动。布局验证见 [小窗口布局](responsive-layout-2026-09-26.md)。

### Gamma 控制项与显示器能力

- Gamma 接口接收 R/G/B 各 256 项的映射表；Gamma、中间调、暗部、高光、黑白位、软件亮度/对比度、RGB 通道增益等可由应用通过曲线计算实现，并受系统与驱动限制。
- 界面建议保留少量常用项，将更多参数收进“高级调节”；候选项不等于全部纳入初版。
- 显示器饱和度纳入初版的条件支持范围；若设备未提供可用的对应控制，则展示不可用状态及原因，不用 Gamma 模拟通用饱和度。
- DDC 能力报告和读取结果用于判断支持情况，区分不支持、当前模式不可用、通信失败及尚未检测，不将所有失败都标成“不支持”。
- 预设只应用在目标显示器上可用的硬件项；其他项应跳过并反馈结果，不默默显示为全部应用成功。
- 每个预设可关闭“使用显示器参数”：只调 Gamma，保留但不应用已保存的硬件数值。未勾选的硬件项保持当前值；切换到仅 Gamma 的预设不会隐式恢复硬件原值。
- DDC/CI 失败只暂停对应硬件控件，不阻止 Gamma、Gamma 预设切换或快捷键。失败项的原值独立保留，用户重新检测或主动恢复时才重试。

### 快捷键交互

- 在预设列表旁显示当前绑定，例如“桌面 F6”“塔科夫 F7”。
- 支持点击快捷键字段后按键录入、修改与清除；快捷键也能在统一设置页管理。
- 使用全局注册，使窗口隐藏到托盘时仍可切换；按住按键不应反复切换预设。
- 录入快捷键期间暂停本应用的全局注册，完成、取消、失焦后恢复，避免录入已有 F 键时先触发预设。
- 检测应用内重复绑定及系统快捷键注册失败，给出明确提示；无法可靠判断游戏内部按键冲突，因此允许用户改为其他 F 键或组合键。
- 遵守 Windows RegisterHotKey 的限制，F12 保留给调试器，不提供为可注册的全局快捷键。

### 窗口、效果与退出

- **关闭窗口（×）**：隐藏到托盘，效果和快捷键继续工作。
- **关闭效果**：恢复调整前状态，程序继续运行，保留当前方案供再次启用。
- **退出程序**：正常退出前恢复调整前状态，然后结束程序。
- 恢复对象是应用调整前的 Gamma 及本应用改动过的显示器参数，不是出厂默认值。
- 首次写入前将原值写入恢复记录。Gamma 与硬件分别保存；硬件记录按显示器 ID 隔离。正常关闭效果或退出时恢复可恢复的原值，硬件失败项保留记录但不阻止 Gamma 使用或正常退出。Gamma 本身无法恢复时仍提示并保留其记录。
- 恢复时重新检测原显示器，通信失败有限重试；部分恢复成功后保存进度，只保留尚未确认恢复的项目。无法恢复时只暂停对应路径，不丢弃原始记录。详见 [Gamma 与硬件故障隔离](gamma-ddc-isolation-2026-09-26.md)。

### 设置

- 浅色 / 深色 / 跟随系统主题，简体中文 / English。
- 手动打开应用时可选择直接进入托盘；默认关闭。
- 启动应用时可自动应用上次保存的预设；默认关闭。
- **不提供 Windows 开机自启，不写启动项或计划任务。**
- 预设及完整配置 JSON 导入 / 导出、能力重检、日志与诊断信息。

## 技术边界

- 初版以 **Windows SDR** 为目标，HDR 下的 Gamma 调节不在支持范围内。
- 初版使用 Gamma 与 DDC/CI，不包含软件颜色矩阵后端。
- Gamma 不能独立实现通用饱和度调节；硬件饱和度通过 DDC/CI 在支持它的显示器上提供。
- 通过系统显示接口与显示器接口工作，不注入游戏、不读取游戏内存、不 Hook DirectX。
- DDC/CI 控制项需根据设备能力和实际响应提供，不假定每台显示器都支持。
- 实时预览不承诺逐帧硬件更新或零延迟，实际应用速度受驱动及显示器影响。
- 需处理显示器连接变化、Gamma 被覆盖、设备写入失败等情况，并明确呈现未成功应用的状态。

## 暂不纳入初版

- 根据前台游戏自动切换预设。
- HDR 调色。
- 软件颜色矩阵与通用软件饱和度调节。
- 多台显示器同时联动的复杂方案。
- Windows 开机自启。

## 当前实现与待验证事项

- 已实现范围见 [development.md](development.md)，技术栈见 [technical-selection.md](technical-selection.md)。
- 每 4 秒空闲检查显示拓扑和已应用 Gamma；检测到变化时暂停效果并尝试恢复，失败时保留恢复记录，不持续抢写。
- 首版产物为依赖系统 WebView2 的 Windows x64 可执行文件；安装包、签名、自动更新留待后续。
- 已进行本机能力只读检测；真实参数写入、游戏内效果、托盘生命周期及睡眠 / 热插拔恢复仍需交互式实机验收。浏览器预览使用独立模拟数据，不代表设备实际能力。

- [Microsoft：RegisterHotKey](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey) — 全局快捷键注册、重复通知与 F12 限制。
