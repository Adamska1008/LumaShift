# 小窗口调节页布局（0.1.4）

原布局按内容自然高度排列，宽屏规则还增大了曲线及参数间距，导致窗口高度不足时整个主区域滚动，对比和快捷键操作落在屏幕外。

改为按可用窗口高度分配调节工作区：顶部显示器选择及预设标题、底部对比与快捷键操作不参与滚动；中间双栏面板占剩余空间。图表高度、留白和行高随窗口收紧；两栏底部对齐。高级项展开时只滚动对应面板内容，折叠入口始终可见。提示信息占独立的限高区域，长错误可滚动阅读；设置和快捷键列表保留正常内容滚动。

本次只改变前端结构和 CSS，以及交付版本号，不修改显示器控制行为。

880×680 下展开高级 Gamma 和更多硬件选项：主区域仍无溢出，面板分别内部滚动。点击最下方黑位输入框可自动滚动到可见位置，未裁掉控件。英文基础页面在 880×680 下同样无溢出；验证后恢复中文演示设置。界面检查使用浏览器演示，没有写入真实显示参数。

TypeScript/Vite、Tauri release 构建及 `git diff --check` 通过。交付：`.local/artifacts/LumaShift-0.1.4.exe`。

## 旧实例导致更新未生效

用户反馈布局没有变化后，查询实际运行进程，发现仍为 `LumaShift-0.1.2.exe`（PID 14508，2026-09-26 22:17:58 启动）。单实例插件会让新启动的程序唤起已有窗口；标题栏原先固定显示 `0.1`，容易误以为已切换新版。

标题栏、关于页和复制诊断现在统一读取 package.json 完整版本号。更新时先在托盘选择“恢复并退出 / Restore & quit”，再打开新版；右上角关闭按钮只隐藏窗口，不能完成版本切换。未强制结束旧进程，避免跳过显示设置恢复。
