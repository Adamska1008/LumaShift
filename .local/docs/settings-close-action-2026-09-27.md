# 设置页与关闭行为（0.1.6）

- 删除设置页宣传语、选项描述和分组底部说明，收紧设置行间距。
- “启动与后台”改为“窗口”，仅保留“关闭窗口时”：隐藏到托盘（默认）或退出程序。
- 原生 CloseRequested 始终阻止直接销毁窗口，按设置隐藏或发送正常 Quit 操作。退出复用 Gamma / 硬件恢复流程，未使用 ForceQuit；恢复失败时沿用原有错误反馈和记录保留逻辑。
- 移除后台启动与启动自动应用逻辑。旧配置及导入文件仍接受 startMinimized / applyLastOnStart，但不再应用，序列化时不输出。新 closeAction 缺省为 tray，仅接受 tray / quit。
- 本次不修改用户运行中的显示设置或配置文件。旧版本文档中关于启动自动应用、LUMASHIFT_SAFE_START 的说明属于历史行为，0.1.6 启动始终显示窗口且不自动应用效果。

## 验证

- 30 项 Rust 测试通过，新增旧设置兼容与无效关闭方式拒绝测试，扩展存储测试验证 quit 设置持久化。
- 浏览器模拟模式验证：关闭方式可以切换，刷新后仍保留；中英文选项正确；截图确认设置页仅显示名称与控件。结束时恢复模拟配置为中文及隐藏到托盘。
- TypeScript / Vite 和 Tauri 发布版构建通过。
- 没有启动原生应用做关闭及真实显示恢复测试，避免干扰正在使用的实例；原生事件分支与既有退出恢复流程已核对。
